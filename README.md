# Painel de Chamados

Painel Kanban estático com sete colunas, arrastar e soltar, inclusão em lote, cópia de chamados e resumo para Teams.

## Privacidade

Esta versão publicada **não contém números reais de chamados** no código. Os chamados ficam apenas no armazenamento local do navegador. Nunca publique arquivos `backup-chamados-*.json` no repositório.

## Como usar

Abra `index.html` ou ative GitHub Pages apontando para a raiz da branch main. Abra o painel no site publicado e importe seu backup JSON pelo botão **Importar backup**.

**Atenção:** o armazenamento local é específico do endereço do site e do navegador, não sincroniza automaticamente entre computadores. Faça backups regulares.
